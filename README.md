# TestAOT

Тестовые приложения и BenchmarkDotNet-бенчмарки для сравнения JIT и Native AOT.

[JSON и XML через рефлексию в Native AOT: настройки, атрибуты, ограничения и проверка](docs/native-aot-reflection-serialization.ru.md).

Документация относится к моделям `ClassLibraryForDeserialization` и бенчмаркам
`JsonSerializationBench` / `XmlSerializationBench` на .NET 10.
